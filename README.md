### DETAILED PROJECT BREAKDOWN

<details>
<summary><b>01 — LEARNOVA</b> &nbsp;│&nbsp; <code>Interactive E-Learning Platform</code></summary>

<br />

**Overview**  
Learnova is a modern web application designed to optimize technical learning workflows through structured modules, real-time progress visualization, and interactive quiz evaluations.

**Technical Architecture**  
- Built with **Next.js** and **React** for server-side rendering and client-side performance.
- Styled with **Tailwind CSS** for custom visual component systems.
- Powered by **Firebase** for real-time state synchronization, authentication, and database services.

**Key Features**  
- Modular curriculum navigation and progress metrics.
- Dynamic interactive quiz engine with instant score calculations.
- Clean responsive layout compatible with desktop and mobile viewports.

**Links**  
[Live Application ↗](https://rishi-n-solanki.vercel.app) &nbsp;·&nbsp; [Source Repository ↗](https://github.com/Rishi-n-s)

</details>

<details>
<summary><b>02 — INTERSTELLAR WORKSPACE</b> &nbsp;│&nbsp; <code>3D WebGL Canvas Environment</code></summary>

<br />

**Overview**  
An experimental web environment exploring real-time 3D graphics rendering, dynamic lighting, and spatial camera movements within the browser.

**Technical Architecture**  
- Developed using **Three.js** and **WebGL** shaders.
- Custom animation loop and interaction controls built in pure **JavaScript**.

**Key Features**  
- Interactive 3D scene camera controls and mesh transformations.
- Optimized rendering loop for consistent frame rates across devices.
